### 2.2 家庭阶段划分

```
现在（2026）→ 2034（约8年）：三口之家 + 孩子上学阶段
    │ 本人主要承担家庭全部月支出
    │ 配偶收入不稳定，全额补充储蓄
    │ 孩子从一年级逐步成长
    ▼
2034 左右：孩子上高中住校

    │ 孩子每月需要住校生活费 ¥1,500-2,000
    ▼
旅居生活启动：双人 + 孩子寒暑假加入
```

**这个时间线非常合理**，8 年后孩子上高中住校，旅居不影响孩子教育，是最优切入点。

### 2.3 债务挑战

现有债务 ¥130,000，年化 3.2%，无固定月供，可随时提前还清。

**每年利息：¥4,160（约 ¥347/月）**

**公积金 vs 债务利率对比：**

| 项目 | 利率 |
|------|------|
| 债务利率 | 3.2%/年 |
| 公积金账户利率 | ~1.5%/年 |
| 净差值 | **-1.7%/年** |

公积金账户里的钱只赚 1.5%，但债务在烧 3.2%，留钱在公积金账户每年净亏 1.7%。**但公积金在职期间无法提前取出，只能在离职时一次性取出，所以无法用于提前还债，必须靠每月结余还款。**

**最快还清计划（优先于旅居和购车）：**

```
第一阶段（第 1-3 个月）：建立应急金
  每月储蓄 ¥5,000 → 3 个月后应急金 ¥15,000 达成

第二阶段（第 4 个月起）：全力还债
  每月还款 ¥5,000（本人结余）
  + 配偶收入有多少投多少（不计入主计划）
  ¥130,000 ÷ ¥5,000 = 26 个月

合计：约 29 个月（2 年 5 个月）债务清零
预计：2028 年下半年前完成
```

| 时间节点 | 债务余额 | 说明 |
|----------|----------|------|
| 现在 | ¥130,000 | — |
| 第 3 个月末 | ¥129,000（仅付利息）| 应急金建立完成 |
| 第 15 个月末 | ~¥69,000 | 还款 12 个月 |
| 第 29 个月末 | **¥0** | 债务清零 🎉 |

配偶每月额外补充 ¥2,000 的情况下，可提前到 **约 20 个月（不到 2 年）** 还清。

### 2.4 储备金挑战

当前无储备资金，但月可储蓄 ¥5,000-6,000（本人）+ 配偶补充，建立速度较快。

**目标：**
- 第 1 年末：应急金 ¥25,000（优先）
- 第 3 年初：购车首付 ¥90,000 达成

### 2.5 公积金资产

**在职期间：** 月提取 ¥1,800（租房提取，已在执行），实际补充到手收入。

**当前账户余额：¥150,000**

**离职时（全额提取）估算：**

| 项目 | 计算 |
|------|------|
| 当前余额 | ¥150,000 |
| 双边月入账 | ¥4,440 |
| 月提取（租房） | -¥1,800 |
| 月净积累 | ¥2,640 |
| 8年净积累 | ¥2,640 × 96 = **¥253,440** |
| 合计（不含利息） | ¥150,000 + ¥253,440 = **¥403,440** |
| 含利息（约1.5%/年）| **约 ¥42-43 万** |

**公积金利率（1.5%）< 债务利率（3.2%）**，但公积金无法提前取出，只能在离职时一次性取出，不可用于加速还债。

**离职时公积金用途（约 ¥42 万）：**
```
├── 旅居启动安全垫（6个月）≈ ¥6-8 万
├── 孩子高中阶段备用金 ≈ ¥3-5 万
├── 购车剩余车贷（如届时未还清）≈ 视情况
└── 剩余 ~¥29-33 万 → 长期储备/理财
```

**核心目标：** 建立应急金 ¥15,000 + 启动渔具店

**储蓄：** 每月结余 ¥5,000 全部存入应急金，3 个月达成 ¥15,000

### 阶段五：正式过渡期（第 7-8 年）

**核心目标：** 离职 → 取出公积金 → 开始旅居

**离职后公积金（约 ¥42 万）用途：**
```
├── 旅居启动安全垫（6个月）≈ ¥7 万
├── 孩子高中备用金 ≈ ¥5 万
├── 购车（视方案）≈ ¥0-30 万
└── 剩余 → 长期储备
```

**收入结构升级**
- 接单收入 + 产品收入组合达到 ¥8,000+/月
- 重点培养 2-3 个长期回头客（维护合同比单次接单稳定得多）
- 考虑小幅提价：随着评价积累和技能提升，时薪/项目单价应逐年上涨

**离职谈判准备**
- 评估当前公司是否支持远程工作
- 若支持：先谈判转为远程员工，这是最低风险的过渡方式
- 若不支持：等副业收入连续 6 个月超过红线后，制定辞职计划

**旅居城市研究**
- 建立备选城市库：成都、大理、厦门、丽江、阳朔、重庆等
- 研究标准：生活成本、网络质量、气候、医疗、双人生活便利性
- 建立每个城市的月度预算估算

**法律和财务准备**
- 注册个体工商户（自由职业收入需要合法开票）
- 了解灵活就业社保缴纳方式（北京/上海户籍有差异）
- 建立记账习惯，了解个人所得税申报流程

---

### 阶段四：正式过渡期（第 7-8 年）

**核心目标：** 完成职业身份切换 + 开始旅居生活

**触发离职的条件（同时满足）：**
- [ ] 副业月收入连续 6 个月 ≥ ¥10,000
- [ ] 储备金余额 ≥ 6 个月双人生活费（约 ¥54,000）
- [ ] 至少有 2 个稳定长期客户在手
- [ ] 完成至少 1 次 1 个月以上的真实旅居验证

**离职后前 3 个月（最脆弱期）：**
- 不急于接大单，先稳定已有客户
- 严格控制支出，不因"自由了"而大幅扩大消费
- 建立工作日程表，避免散漫导致效率崩塌

**旅居启动：**
- 第一站选择生活成本低、基础设施好的城市（成都 / 大理 推荐首选）
- 不要一开始就去过于偏僻的地方，初期需要稳定网络和便利生活
- 住宿优先选月租民宿或短租公寓（比酒店便宜、比年租灵活）

## 五、渔具电商渠道策略

### 5.1 销售平台优先级

| 平台 | 特点 | 启动建议 |
|------|------|----------|
| **闲鱼** | 零门槛，钓鱼二手/新品都有需求，适合冷启动 | ✅ 第一个注册 |
| **淘宝** | 主流，搜索流量大，运营门槛适中 | ✅ 同步开店 |
| **抖音小店** | 内容带货，远投视频天然引流 | 第 2-3 个月开通 |
| **1688 采购** | 货源渠道，寻找代发供应商 | 同步研究 |

### 5.2 内容引流策略

```
第 1 优先：GoCasting App 用户 → 店铺（精准 + 零成本）
第 2 优先：抖音/小红书远投内容 → 主页店铺链接
第 3 优先：厦门本地钓友群/微信社群 → 私域复购
第 4 优先：淘宝自然搜索流量
```

### 5.3 GoCasting 联动实现路径

- App 内「装备推荐」模块：展示参考数据库中的竿/轮，附「购买」按钮跳转店铺
- 「渔获日志」关联装备：用户记录使用了哪款装备 → 引导评价/购买同款
- 「愿望单」功能：用户收藏装备 → 定期推送店铺优惠信息（App 内通知）

```
第 1 优先：老客户复购 + 转介绍（零成本，最高质量）
第 2 优先：程序员客栈/猿急送（有评价后）
第 3 优先：技术内容输出带来的被动询单
第 4 优先：猪八戒等大平台（初期用，中后期减少依赖）
```

## 十一、购车方案

车是旅居生活方式的基础设施，但不是必须品。根据财务进展，设置三个方案，债务清零后根据实际情况决策。

### Plan A — 不买车（优先推荐，财务压力最小）

**旅居出行方式：**
- 城市间：高铁（厦门→成都约 5.5h，¥400-600/人）
- 城市内：地铁 + 滴滴 + 共享单车
- 偶尔跨城：租车（一天 ¥150-300）

**月均交通成本估算：**
| 场景 | 费用 |
|------|------|
| 旅居城市内日常 | ¥500-800/月 |
| 城市间迁移（半年一次）| ¥800-1,200/次 |
| **月均折算** | **约 ¥700-1,000** |

**优势：**
- 无车贷压力，离职红线降至 ¥10,000-11,000（可提前离职）
- 停车费/保险/保养全省
- 旅居城市如大理/厦门/成都公共交通完全够用

**劣势：**
- 大件行李运输不便（渔具/钓竿需要托运）
- 自由度低于有车，去偏远钓点不便

不要在经济尚未独立时就急于旅居。8 年的时间线给了充足的准备空间，不要压缩它。

**4. 伴侣是最重要的变量**
双人旅居意味着两个人的生活节奏、消费习惯、对不确定性的容忍度都要对齐。这个对话越早开始越好。

**5. 技能的护城河在于交付质量**
接单平台上最终的竞争力不是价格，而是按时交付 + 沟通顺畅 + 代码质量。三点做好，自然有转介绍。
