## 架构模式

采用 **功能优先的模块化单体** 架构：

```
┌──────────────────────────────────────────┐
│              UI 层 (Screens)              │
├──────────────────────────────────────────┤
│          控制器层 (GetX Controllers)       │
├──────────────────────────────────────────┤
│           领域逻辑层 (Domain)             │
├──────────────────────────────────────────┤
│            数据访问层 (Data)              │
├──────────────────────────────────────────┤
│         核心层 (Database/Services)        │
└──────────────────────────────────────────┘
```

每个功能模块内部遵循分层结构：
- `presentation/` — UI 页面（StatelessWidget + Obx）
- `domain/` — 业务逻辑（纯 Dart 函数/类）
- `data/` — 数据访问仓库
- `providers/` — GetX 控制器

## 数据库设计

### 双数据库分离策略

| 数据库 | 文件 | 模式 | 用途 |
|--------|------|------|------|
| reference.db | `assets/db/` | 只读 | 装备目录、潮汐站、海滩、鱼种 |
| user.db | `app_documents/` | 可写 | 用户装备、日志、设置 |

### 参考数据库表（7 张）

| 表名 | 用途 |
|------|------|
| Rods | 鱼竿参考数据 |
| Reels | 渔轮参考数据 |
| Lines | 钓线参考数据 |
| TerminalTackle | 末端配件（钩/铅/转环） |
| TideStations | 潮汐站+谐波常数 |
| Beaches | 海滩信息 |
| Species | 目标鱼种 |

### 用户数据库表（10 张，Schema V3）

| 表名 | 版本 | 用途 |
|------|------|------|
| UserGear | V1 | 用户装备库存 |
| UsageLogs | V1 | 使用记录 |
| MaintenanceLogs | V1+V2 | 维护记录（含费用） |
| CustomBeaches | V1 | 自定义海滩 |
| UserSettings | V1 | 设置键值对 |
| GearWarranties | V2 | 保修信息 |
| GearPhotos | V2 | 照片/收据 |
| ServiceRecords | V2 | 维修状态追踪 |
| GearComponents | V2 | 零件/子组件 |
| CatchLogs | V3 | 渔获日志 |

### 迁移策略

```
Schema V1 → V2: 添加 cost/costCategory/serviceProvider 到 MaintenanceLogs
                 创建 GearWarranties/GearPhotos/ServiceRecords/GearComponents
Schema V2 → V3: 创建 CatchLogs 表
```

## 关键架构决策

| ID | 决策 | 理由 |
|----|------|------|
| AD-1 | 高德地图（非瓦片） | 中国大陆可用，在线获取地图 |
| AD-2 | NOAA 潮汐谐波 | 公开数据，纯 Dart 计算 |
| AD-3 | GetX 状态管理 | 轻量、简洁、路由+DI 一体 |
| AD-4 | Drift SQLite | 编译时查询验证，类型安全 |
| AD-5 | 双数据库分离 | 参考数据不可变，用户数据独立 |
| AD-6 | 纯 Dart 天文计算 | 跨平台一致，可纯函数测试 |
| AD-7 | 照片本地持久化 | 无云存储依赖 |
| AD-8 | 仅本地通知 | 无推送服务，无 FCM |
| AD-9 | geolocator 替代 amap_location | amap_flutter_location iOS SDK 不兼容 |
| AD-10 | Schema 迁移策略 | Drift MigrationStrategy 按版本顺序执行 |
