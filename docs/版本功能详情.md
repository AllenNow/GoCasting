## V1：基础功能（项目脚手架）

### 1.1 装备推荐向导

通过问答式交互（目标鱼种 → 环境 → 预算）为用户推荐最适合的远投装备组合。

- **实现文件：** `features/gear/presentation/gear_wizard_screen.dart`
- **领域逻辑：** `features/gear/domain/recommendation_engine.dart`
- **状态管理：** `features/gear/domain/gear_wizard_state.dart`
- **工作原理：** 根据用户选择的条件（鱼种、环境、预算等级）从参考数据库筛选匹配装备，按评分排序推荐

### 1.2 兼容性检查

检查竿/轮/线组合的兼容性，提示不匹配项。

- **实现文件：** `features/gear/domain/compatibility_checker.dart`
- **检查维度：** 线径 vs 轮容量、竿负荷 vs 铅重、竿 power vs 线 lb 数、轮 drag vs 目标鱼种

### 1.3 装备对比

支持同类装备的规格参数并排对比。

- **实现文件：** `features/gear/presentation/gear_compare_screen.dart`
- **对比维度：** 重量、价格、齿比、刹车力、线容量等核心参数

### 1.4 参考数据库浏览

以列表/筛选方式浏览所有内置装备参考数据。

- **实现文件：** `features/gear/presentation/gear_browse_screen.dart`
- **筛选条件：** 品牌、类型、价格等级、系列

### 1.5 装备库存管理

用户注册自己拥有的装备到系统中，追踪状态（活跃/存放/退役）。

- **实现文件：** `features/maintenance/presentation/add_gear_screen.dart`
- **数据表：** `UserGear`（user_db）
- **状态：** active / stored / retired

### 1.6 使用日志

每次出钓后记录使用环境和时长，用于维护调度计算。

- **数据表：** `UsageLogs`
- **记录内容：** 日期、环境（saltwater/brackish/rinse-only）、时长

### 1.7 维护调度器 + 通知

基于使用记录和规则引擎，自动计算下次维护时间并推送本地通知。

- **规则引擎：** `features/maintenance/domain/maintenance_scheduler.dart`
- **通知服务：** `core/notifications/notification_service.dart`
- **调度规则：** 盐水使用后 X 天需维护、达到 Y 次使用需全面保养

### 1.8 潮汐预测（谐波分析）

使用 NOAA 谐波常数进行纯 Dart 潮汐高度预测。

- **实现文件：** `features/planner/domain/tide_predictor.dart`
- **算法：** 基于主要分潮（M2、S2、N2、K1、O1 等）的谐波叠加
- **精度：** 仅保证美国海岸

### 1.9 月相 / 日出日落 / Solunar

纯 Dart 天文计算，无外部依赖。

- **实现文件：** `features/planner/domain/astronomy.dart`
- **计算内容：** 月相百分比、日出/日落时间、月出/月落、Solunar 活跃期
- **约束：** 仅使用 `dart:math` 和 `dart:core`

### 1.10 出行规划仪表板

整合潮汐、天文、天气信息的综合规划视图。

- **实现文件：** `features/planner/presentation/planner_screen.dart`

### 1.11 海滩数据库

内置海滩信息，关联最近潮汐站。

- **数据表：** `Beaches`（reference_db）
- **字段：** 名称、地区、坐标、类型、常见鱼种

### 1.12 新手引导

首次启动的引导流程。

- **实现文件：** `features/onboarding/onboarding_screen.dart`

## V2：装备生命周期管理

### 2.1 保修追踪 + 到期通知

记录保修信息，到期前自动推送通知提醒。

- **实现文件：** `features/maintenance/presentation/warranty_screen.dart`
- **数据表：** `GearWarranties`
- **通知：** 到期前 30 天/7 天提醒

### 2.2 收据/照片存储

使用 `image_picker` 拍照或从相册选择，本地持久化存储。

- **实现文件：** `features/maintenance/presentation/photos_screen.dart`
- **数据表：** `GearPhotos`
- **照片类型：** gear（装备照）、receipt（收据）、warranty_card（保修卡）、invoice（发票）
- **存储策略：** 压缩至 1920px/85% 质量，存放在 `app_documents/gear_photos/`

### 2.3 维护费用 + TCO 分析

记录每次维护的费用，计算装备总拥有成本。

- **实现文件：** `features/maintenance/presentation/tco_analysis_screen.dart`
- **分析维度：** 购买价 + 累计维护费 = 总 TCO、每次出钓平均成本、费用分类统计

### 2.4 折旧/估值引擎

基于购买价格、使用时间和状态计算当前市场估值。

- **实现文件：** `features/maintenance/domain/depreciation_engine.dart`
- **折旧方法：** 直线法 + 使用强度调整
- **显示：** `features/maintenance/presentation/valuation_card.dart`

### 2.5 零件级别追踪

追踪渔轮轴承、刹车片、线杯等子组件的独立维护周期。

- **实现文件：** `features/maintenance/presentation/components_screen.dart`
- **数据表：** `GearComponents`
- **追踪内容：** 安装日期、使用次数、更换费用、独立维护间隔

### 2.6 维护教程（6 篇）

内置图文教程，指导用户进行常见维护操作。

- **实现文件：** `features/maintenance/domain/maintenance_tutorials.dart`
- **教程列表：**
  1. 渔轮全面清洗
  2. 刹车脂更换
  3. 线杯检查与更换
  4. 导环检查
  5. 竿节维护
  6. 冬季存放指南

### 2.7 专业维修状态追踪

追踪送修装备的状态（送出 → 维修中 → 返回）。

- **实现文件：** `features/maintenance/presentation/service_records_screen.dart`
- **数据表：** `ServiceRecords`
- **状态流：** sent → in_repair → returned

### 2.8 季前检查清单

根据装备类型和存放时长自动生成检查项目。

- **实现文件：** `features/maintenance/presentation/preseason_checklist_screen.dart`
- **领域逻辑：** `features/maintenance/domain/preseason_checklist.dart`
- **优先级：** 关键 / 常规 / 可选
- **规则：** 存放超 90 天追加额外检查项

### 2.9 保险报告导出

汇总所有活跃装备的估值信息，生成 CSV 报告用于保险申报。

- **实现文件：** `features/maintenance/presentation/insurance_report_screen.dart`
- **输出格式：** CSV（含报告头和装备明细）
- **操作：** 导出文件 / 复制到剪贴板

### 2.10 CSV 导出

通用数据导出能力。

- **实现文件：** `features/maintenance/domain/csv_exporter.dart`

## V3：钓鱼工具箱

### 3.1 Go-Score 评分系统

4 因子综合评分（潮汐 + 月相 + 天气 + 时段），0-100 分。

- **实现文件：** `features/planner/domain/go_score.dart`
- **UI：** `features/planner/presentation/go_score_screen.dart`
- **评分因子：**
  - 潮汐状态（涨/落/高/低）
  - 月相（满月/新月加分）
  - Solunar 活跃期重叠
  - 时段（黎明/黄昏最优）

### 3.2 计算器工具箱（4 个）

- **实现文件：** `features/gear/domain/fishing_calculators.dart`
- **UI：** `features/gear/presentation/calculators_screen.dart`
- **计算器列表：**
  1. **拖力设置计算器** — 根据线 lb 数计算推荐 drag 值
  2. **线容量计算器** — 根据线径和线杯尺寸计算可容纳长度
  3. **Shock Leader 计算器** — 根据铅重计算前导线 lb 数
  4. **铅坠重量计算器** — 根据流速/风力推荐铅重

### 3.3 绳结/钓组指南

内置远投常用绳结和钓组的图文指南。

- **实现文件：** `features/gear/domain/knots_and_rigs.dart`
- **UI：** `features/gear/presentation/knots_rigs_screen.dart`
- **内容：** 8 种绳结 + 5 种远投钓组

### 3.4 出行装载清单

根据出钓场景智能生成装备清单。

- **实现文件：** `features/planner/domain/trip_checklist.dart`
- **UI：** `features/planner/presentation/trip_checklist_screen.dart`
- **场景模板：** 5 种（沙滩远投、堤防、矶钓、夜钓、竞技）

### 3.5 鱼种图鉴（15 种）

远投目标鱼种信息库。

- **实现文件：** `features/gear/domain/species_guide.dart`
- **UI：** `features/gear/presentation/species_guide_screen.dart`
- **每种鱼信息：** 习性、推荐装备、最佳时段、推荐饵料

### 3.6 装备愿望单

收藏想购买的装备，记录目标价格。

- **实现文件：** `features/gear/presentation/wishlist_screen.dart`

### 3.7 远投距离追踪

记录和统计抛投距离，追踪进步。

- **实现文件：** `features/planner/domain/cast_tracker.dart`
- **UI：** `features/planner/presentation/cast_tracker_screen.dart`

## V4：渔获分析

### 4.1 渔获日志

完整的渔获记录系统，关联装备、位置、条件。

- **数据表：** `CatchLogs`（user_db schema v3）
- **UI：** `features/catch_log/presentation/catch_log_screen.dart`
- **记录字段：** 鱼种、重量、长度、照片、装备、饵料、钓组、位置、潮汐、天气、是否放流

### 4.2 条件关联分析引擎

分析什么条件下钓获最多，生成数据洞察。

- **实现文件：** `features/catch_log/domain/catch_analysis.dart`
- **分析维度（6 个）：**
  1. 潮汐状态关联
  2. 天气条件关联
  3. 时段分布
  4. 饵料效果对比
  5. 钓组效果对比
  6. 位置热点
- **洞察输出（6 个）：** 最佳潮汐、最佳时段、最佳饵料、最佳钓组、热点位置、季节趋势

## V5：在线功能集成

### 5.1 高德地图集成

显示钓点地图，支持添加自定义钓点。

- **实现文件：** `core/map/amap_service.dart`
- **UI：** `features/planner/presentation/spot_map_screen.dart`
- **功能：** 地图显示、标记钓点、GPS 定位当前位置
- **依赖：** `amap_flutter_map ^3.0.0` + `amap_flutter_base ^3.0.0`

### 5.2 GPS 定位

使用 geolocator 获取当前位置（替代 amap_flutter_location，后者 iOS SDK 不兼容）。

- **依赖：** `geolocator ^13.0.2` + `permission_handler ^11.3.1`
- **权限：** 使用时定位（不使用后台定位）

### 5.3 实时天气 + 钓鱼指数

调用高德天气 API 获取实况和预报，计算钓鱼适宜度。

- **实现文件：** `core/weather/weather_service.dart`
- **UI：** `features/planner/presentation/weather_card.dart`
- **内容：** 实况天气卡片、钓鱼适宜评分、3 天预报

### 5.4 附近 POI 搜索（6 类）

搜索钓点附近的便利设施。

- **实现文件：** `core/weather/nearby_search_service.dart`
- **UI：** `features/planner/presentation/nearby_screen.dart`
- **搜索类别：** 停车场、便利店、卫生间、渔具店、加油站、餐饮
- **功能：** 列表显示 + 一键导航

### 5.5 本地角色系统（5 角色）

根据用户类型差异化显示功能入口。

- **实现文件：** `core/roles/role_controller.dart` + `role_model.dart`
- **UI：** `core/roles/role_selection_screen.dart`
- **5 种角色：** 入门新手、休闲钓手、远投竞技、装备控、全能型
- **实现方式：** 本地持久化，无需后端认证

### 5.6 暗色模式

跟随系统设置自动切换亮/暗主题。

- **实现方式：** `ThemeMode.system` in `main.dart`
- **主题定义：** `app/theme.dart`（Material 3 亮色+暗色）

- **实现文件：** `features/achievements/domain/achievement_engine.dart`

## 基础设施功能

### 数据备份/恢复

- **实现文件：** `core/backup/backup_service.dart` + `backup_restore_screen.dart`
- **备份格式：** `.gcbak`（ZIP 压缩包）
- **备份内容：** user.db + 照片目录（7 个数据模块）
- **操作：** 导出到文件系统 / 从文件恢复

### 国际化

- **文件：** `l10n/app_en.arb` + `l10n/app_zh.arb`
- **覆盖：** ~230 个翻译键
- **范围：** 所有 V1-V8 页面的 UI 文本
- **切换：** 跟随系统语言，支持手动切换

### 本地通知

- **实现文件：** `core/notifications/notification_service.dart`
- **用途：** 维护提醒、保修到期提醒
- **方式：** 精确闹钟 API，无推送服务

### 双数据库

- **reference.db：** 7 张表，只读，App Bundle 内
- **user.db：** 10 张表，可写，WAL 模式，Schema V3
- **迁移：** V1→V2→V3 顺序迁移策略

### Android 自动备份

- **配置：** `AndroidManifest.xml` 中 `android:allowBackup="true"`
- **范围：** App 内部数据自动备份到 Google Drive
