# GoCasting 项目总览与功能进度

> 最后更新：2026-07-16

## 项目简介

GoCasting 是一款面向远投海钓（Surf Casting）爱好者的 Flutter 应用，支持 iOS 和 Android。应用覆盖装备管理、出行规划、渔获记录、数据分析和趣味互动等核心场景。

## 导航结构

应用采用 5 Tab 底部导航：

```
┌─────────────────────────────────────────────┐
│  首页(Home)  │  装备(Gear)  │  渔获(Catches)  │  规划(Planner)  │  我的(Me)  │
└─────────────────────────────────────────────┘
```

- **首页**：数据仪表板、Go-Score、AI 教练建议
- **装备**：装备向导、库存管理、计算器、绳结指南、鱼种图鉴
- **渔获**：渔获日志、条件关联分析
- **规划**：地图钓点、天气、潮汐、出行清单、远投追踪
- **我的**：个人资料、成就、挑战、设置、备份、趣味区
