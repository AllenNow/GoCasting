### 型号命名规律

JDM 远投竿型号编号表示铅负荷等级：
- **AX** — 最轻负荷（极细线远投, #20-27 号铅）
- **BX** — 大负荷力投型（#27-35 号铅）
- **CX** — 中荷重万能型（#25-33 号铅）
- **DX** — 轻负荷标准远投（#23-30 号铅）
- **EX** — 轻量高感度型（#20-27 号铅）
- **FX** — 超大负荷型（#33-40 号铅，Kisu Special 独有）

数字标记：
- **405** = 4.05m 长度
- **425** = 4.25m 长度
- **-T** = Telescopic（振出式）

### 数据字段

基础字段（西方竿）：
- `brand` / `model` / `length_ft` / `power` / `action`
- `material` / `cast_weight_min_oz` / `cast_weight_max_oz`
- `line_rating` / `price_tier` / `corrosion_rating` / `pieces`

JDM 专用扩展字段：
- `length_m` / `weight_g` / `sinker_load` — 日本号数铅负荷
- `closed_length_cm` / `tip_diameter_mm` / `butt_diameter_mm`
- `reel_seat_mm` / `standard_sinker`
- `type` — telescopic / put-in_joint / spinning
- `year` / `market` / `description`
